BUG-U04 — Dark mode resets when navigating between pages
Severity: Medium        Status: STILL OPEN
Area: Theme / appearance — global
Description: When dark mode is enabled, simply navigating to another page (for example, from 
Projects to Suppliers) causes the app to revert to white/light mode. The theme setting is not persisted 
across page transitions.
Steps to reproduce: 1) Enable dark mode while on the Projects page. 2) Navigate to the Suppliers 
page (or any other page). 3) Observe the theme.
Expected: Dark mode persists across all pages until the user explicitly disables it.
Actual: Theme reverts to white/light mode on every page navigation.
Retest note: Originally reported in Round 1 as an issue triggered by sidebar navigation / screenshots. 
In Round 2 the trigger is even broader — any page-to-page navigation resets the theme.

BUG-F14 — Bank Reconciliation — CSV upload still fails (now reports missing date 
column)
Severity: Critical        Status: STILL OPEN
Area: Bank Reconciliation → Upload CSV
Description: Uploading a CSV file returns "An error occurred — CSV is missing a date column. 
Expected one of: date, transaction date, value date, posting date,   ,تاريختاريخالمعاملة Important: the user 
confirms the uploaded CSV already contains a date column. The parser is not detecting the date 
column correctly.
Steps to reproduce: 1) Bank Reconciliation page. 2) Upload a CSV file that contains a date column 
with a standard header.
Expected: CSV is parsed; transactions are loaded for matching.
Actual: Error dialog: "CSV is missing a date column..." even when the column is present in the file. 
(See screenshot below.)
Retest note: Round 2 retest — error message has changed from a generic load error to a specific (but 
incorrect) date-column error. The parser logic for detecting date columns is broken or too strict (it may 
not recognize the user's exact column header). Recommend: log the raw CSV header server-side, and 
broaden the matching logic (case-insensitive, trim, allow common variants).Round 2 retest — Bank Reconciliation rejects a CSV that does contain a date column.
