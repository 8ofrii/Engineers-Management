### 3. Transactions V1.2 (Profit on Expense)

#### Create Income Transaction
```bash
POST /api/transactions
Authorization: Bearer <token>
Content-Type: application/json

{
  "type": "INCOME",
  "category": "PAYMENT",
  "amount": 100000,
  "projectId": "project-uuid",
  "projectCostItemId": "cost-item-uuid",  // Optional
  "description": "Client payment for Phase 1",
  "transactionDate": "2026-02-10T14:30:00Z",  // Optional, defaults to now
  "paymentMethod": "BANK_TRANSFER",
  "invoiceNumber": "INV-2026-001"
}

Response:
{
  "success": true,
  "data": {
    "id": "transaction-uuid",
    "type": "INCOME",
    "amount": 100000,
    // ... transaction details
  },
  "profitInfo": {
    "type": "INCOME",
    "amountToSafe": 100000,
    "profitRecognized": 0,
    "message": "Full amount added to Project Safe. Profit will be recognized on expenses."
  }
}
```

#### Create Expense Transaction (Direct Cost)
```bash
POST /api/transactions
Authorization: Bearer <token>
Content-Type: application/json

{
  "type": "EXPENSE",
  "category": "MATERIALS_CEMENT",  // Using Arabic category key
  "amount": 10000,
  "projectId": "project-uuid",
  "projectCostItemId": "cost-item-uuid",  // Optional
  "description": "اسمنت للطابق الأول",
  "transactionDate": "2026-02-10T14:30:00Z",
  "paymentMethod": "CASH",
  "payerUserId": "engineer-uuid",  // Optional, for managers only
  "createBatch": false  // false = recognize profit now
}

Response:
{
  "success": true,
  "data": {
    "id": "transaction-uuid",
    "type": "EXPENSE",
    "amount": 10000,
    // ... transaction details
  },
  "profitInfo": {
    "profit": 2000,  // Assuming 20% management fee
    "projectSafeAfter": 88000,  // 100k - 10k - 2k
    "officeRevenueAfter": 2000,
    "message": "Profit of 2000 EGP recognized and transferred to office revenue."
  }
}
```

#### Create Expense Transaction (Inventory Purchase)
```bash
POST /api/transactions
Authorization: Bearer <token>
Content-Type: application/json

{
  "type": "EXPENSE",
  "category": "MATERIALS_CEMENT",
  "amount": 15000,
  "projectId": "project-uuid",
  "description": "Bulk cement purchase for storage",
  "createBatch": true  // true = defer profit until usage

Response:
{
  "success": true,
  "data": {
    "id": "transaction-uuid",
    "type": "EXPENSE",
    "amount": 15000,
    // ... transaction details
  },
  "profitInfo": {
    "profit": 0,
    "message": "Inventory batch created. Profit deferred until usage."
  }
}
```

## 🧪 Testing Scenarios

### Scenario 1: Complete Project Flow with V1.2 Logic

```bash
# 1. Create a project cost item
POST /api/project-cost-items
{
  "projectId": "proj-123",
  "name": "Foundation Work",
  "totalQuantity": 50,
  "unitOfMeasure": "M3",
  "unitPrice": 500,
  "estimatedTotal": 25000
}

# 2. Record client income
POST /api/transactions
{
  "type": "INCOME",
  "amount": 100000,
  "projectId": "proj-123",
  "description": "Initial payment"
}
# Result: projectSafeBalance = 100,000 EGP

# 3. Record expense (direct cost)
POST /api/transactions
{
  "type": "EXPENSE",
  "category": "MATERIALS_CONCRETE",
  "amount": 10000,
  "projectId": "proj-123",
  "projectCostItemId": "cost-item-from-step-1"
}
# Result: 
# - projectSafeBalance = 88,000 (100k - 10k - 2k profit)
# - officeRevenue = 2,000 (20% profit)
# - Cost item totalPaid = 10,000

# 4. Purchase inventory
POST /api/transactions
{
  "type": "EXPENSE",
  "category": "MATERIALS_CEMENT",
  "amount": 15000,
  "projectId": "proj-123",
  "createBatch": true
}
# Result:
# - projectSafeBalance = 73,000 (88k - 15k)
# - Material batch created
# - No profit yet (deferred)

# 5. Use inventory
POST /api/transactions/inventory-usage
{
  "materialBatchId": "batch-from-step-4",
  "valueConsumed": 5000,
  "projectId": "proj-123"
}
# Result:
# - projectSafeBalance = 72,000 (73k - 1k profit)
# - officeRevenue = 3,000 (2k + 1k profit)
```

## 🔧 Troubleshooting

### Issue: Categories not showing
**Solution:** Ensure `/api/categories` endpoint is accessible and returns data

### Issue: Profit not calculated
**Check:**
- Project has `revenueModel = 'EXECUTION_COST_PLUS'`
- Project has `managementFeePercent` set (e.g., 20)
- Transaction is not an inventory purchase (`createBatch = false`)

### Issue: Safe balance not updating
**Check:**
- Migration applied successfully
- `projectSafeBalance` column exists in database
- Using V1.2 logic (not old recordIncome endpoint)

---

## 📝 Notes

1. **All amounts are in EGP** (Egyptian Pounds)
2. **Profit is calculated on expense**, not income
3. **Inventory profit is deferred** until usage
4. **Categories use Arabic terms** as primary labels
5. **Managers can assign payers** using `payerUserId`
6. **Transaction dates are editable** (defaults to now)
