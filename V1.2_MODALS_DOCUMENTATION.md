## 1. TransactionModal Component

**File:** `client/src/components/TransactionModal.jsx`

### Purpose
Create and edit transactions with V1.2 "Profit on Expense" logic support.

### Features
- ✅ **Bilingual Support** - Arabic/English with RTL support
- ✅ **Transaction Types** - Income & Expense
- ✅ **Arabic Categories** - Fetched from `/api/categories`
- ✅ **Date & Time Picker** - Editable transaction date (defaults to now)
- ✅ **Work Order Linking** - Link to Project Cost Items
- ✅ **Payer Selection** - Managers can assign payer (payerUserId)
- ✅ **Inventory Toggle** - Create batch for inventory purchases
- ✅ **Inline Cost Item Creation** - Create new work orders without closing modal
- ✅ **Real-time Validation** - Field-level error messages

### Props

```javascript
{
  open: boolean,              // Modal open state
  onClose: function,          // Close handler
  onSubmit: function,         // Submit handler (receives formData)
  projectId: string,          // Current project ID
  currentUser: object         // Current user object with role
}
```

### Usage Example

```jsx
import TransactionModal from './components/TransactionModal';

function ProjectPage() {
  const [modalOpen, setModalOpen] = useState(false);
  const currentUser = useAuth(); // Your auth hook

  const handleSubmit = async (formData) => {
    try {
      const response = await fetch('/api/transactions', {
        method: 'POST',
        headers: {
          'Content-Type': 'application/json',
          'Authorization': `Bearer ${token}`
        },
        body: JSON.stringify(formData)
      });
      
      const data = await response.json();
      
      if (data.success) {
        // Show success message
        console.log('Profit Info:', data.profitInfo);
        // Refresh transactions list
      }
    } catch (error) {
      console.error('Failed to create transaction:', error);
    }
  };

  return (
    <>
      <Button onClick={() => setModalOpen(true)}>
        New Transaction
      </Button>
      
      <TransactionModal
        open={modalOpen}
        onClose={() => setModalOpen(false)}
        onSubmit={handleSubmit}
        projectId={projectId}
        currentUser={currentUser}
      />
    </>
  );
}
```

### Form Data Structure

```javascript
{
  type: 'INCOME' | 'EXPENSE',
  category: string,                    // Category key (e.g., 'MATERIALS_CEMENT')
  amount: number,
  description: string,
  projectCostItemId: string | null,    // Optional work order link
  transactionDate: Date,               // Editable date/time
  paymentMethod: string,               // CASH, BANK_TRANSFER, CHECK, etc.
  payerUserId: string,                 // User who paid (for managers)
  invoiceNumber: string,               // Optional
  createBatch: boolean                 // True for inventory purchases
}
```

## 2. CostItemModal Component

**File:** `client/src/components/CostItemModal.jsx`

### Purpose
Create and edit Project Cost Items (Work Orders/Bands).

### Features
- ✅ **Bilingual Support** - Arabic/English with RTL
- ✅ **Auto-calculation** - Estimated total = Quantity × Unit Price
- ✅ **Create & Edit Modes** - Single component for both
- ✅ **Validation** - Required field checking
- ✅ **Loading States** - Disabled during submission

### Props

```javascript
{
  open: boolean,              // Modal open state
  onClose: function,          // Close handler
  projectId: string,          // Current project ID
  onSuccess: function,        // Success handler (receives created/updated item)

}
```

```jsx

    <>
      {/* Create New */}
      <Button onClick={() => {
        setEditingItem(null);
        setModalOpen(true);
      }}>
        New Cost Item
      </Button>

      {/* Edit Existing */}
      <Button onClick={() => {
        setEditingItem(existingItem);
```

## 3. InventoryUsageModal Component

**File:** `client/src/components/InventoryUsageModal.jsx`

### Features
- ✅ **Bilingual Support** - Arabic/English with RTL
- ✅ **Batch Selection** - Shows available batches with remaining values

### Props

```javascript
{
  open: boolean,              // Modal open state
  onClose: function,          // Close handler
  projectId: string,          // Current project ID
  onSuccess: function         // Success handler (receives usage data & profitInfo)
}
```

## 🔧 Integration Checklist

### 1. Install Dependencies
```bash
npm install @mui/material @mui/x-date-pickers @mui/icons-material react-i18next date-fns
```

### 2. Setup i18n
Create `i18n.js`:
```javascript
import i18n from 'i18next';
import { initReactI18next } from 'react-i18next';

i18n
  .use(initReactI18next)
  .init({
    resources: {
      en: { translation: { /* English translations */ } },
      ar: { translation: { /* Arabic translations */ } }
    },
    lng: 'en',
    fallbackLng: 'en',
    interpolation: { escapeValue: false }
  });

export default i18n;
```

### 3. Wrap App with Providers
```jsx
import { LocalizationProvider } from '@mui/x-date-pickers/LocalizationProvider';
import { AdapterDateFns } from '@mui/x-date-pickers/AdapterDateFns';
import { I18nextProvider } from 'react-i18next';
import i18n from './i18n';

function App() {
  return (
    <I18nextProvider i18n={i18n}>
      <LocalizationProvider dateAdapter={AdapterDateFns}>
        {/* Your app */}
      </LocalizationProvider>
    </I18nextProvider>
  );
}
```

### 4. Import and Use Modals
```jsx
import TransactionModal from './components/TransactionModal';
import CostItemModal from './components/CostItemModal';
import InventoryUsageModal from './components/InventoryUsageModal';
```

## 🆘 Troubleshooting

### Issue: Categories not loading
**Solution:** Ensure `/api/categories` endpoint is accessible and returns grouped data

### Issue: Date picker not working
**Solution:** Check that `@mui/x-date-pickers` and `date-fns` are installed

### Issue: RTL not working for Arabic
**Solution:** Ensure `dir={isArabic ? 'rtl' : 'ltr'}` is set on Dialog component

### Issue: Profit preview not showing
**Solution:** Verify project has `managementFeePercent` set and is COST_PLUS model
